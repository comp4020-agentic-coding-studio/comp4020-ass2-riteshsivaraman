02 Premise
The premise

Nobody assesses your work. They assess your work as presented.

Presentation is not an optional extra layer sitting on top of the real thing. It is the only channel a reader ever gets back to what you actually did.

03
03 Same project

The same project, twice — bare and framed

Bare

Identical underlying work with no framing decisions made at all: no named constraint, no stated part, no result up front. Nothing about the work itself differs from the panel beside it.

Framed

The same work, presented against the four questions an assessor actually runs. Ask the room which one they would open on a Friday afternoon.

04
04 The read
The ninety-second read

Four questions an assessor actually runs

  1. What is it?

  2. Does it work?

  3. Did you do it?

  4. Do I care?

05
05 Thin varnish
Thin varnish: four moves

One sentence each, demonstrated on a single artefact

  1. Name the problem.

  2. Show the thing running.

  3. State your part.

  4. State the constraint.

06 Thick varnish
Thick varnish: four tells

Deliberately the same shape as the last slide

Adjectives standing in for outcomes, no named constraint, passive voice wherever ownership should sit, and finish inversely proportional to depth.

The class red-teams exactly these tells in week 08 — call one before it is named for you.

Where the gallery walk starts for each stream

  2. Creative — portfolio case study.

  3. Commercial — one-page capability brief.

Live teardown of one real-ish artefact

Annotated slowly, in front of the room, showing what its varnish is doing at each point.

The room calls the tell before it is named — that is the exercise, not a rhetorical question.

09 Whose work
The integrity boundary

Whose work was it — attribution and the word “we”

Said plainly, not hedged. Overclaiming a team output is the most common portfolio failure, and among the easiest for a reader to detect.
